# 单句语法填空 · 5分钟挑战

高考语法填空**单句**速练：题干给一句真题句子（含提示词），四选一，每题倒计时 **15 秒**，总时长默认 **5 分钟**，题库 **500 题**随机不重复。

## 怎么用

- **电脑 / 投屏**：双击 `index.html` 即可，无需联网、无需安装。
- **手机 / 平板**：把整个文件夹拷到手机上（或用局域网访问），用浏览器打开 `index.html`。
- 首页可选：总时长（3/5/10 分钟）、每题限时（10/15/20 秒）、考点范围（可只练某一类）、答题节奏。
- 答题页按键盘 `1 2 3 4` 或 `A B C D` 选择，`空格/回车` 下一题，`Esc` 暂停。
- 投屏讲解建议选「答错后停住讲解」，答错时画面停住，讲完按空格再继续。

规则：15 秒内未选择即判错；总时间耗尽自动结算；结算页有正确率、考点掌握情况、错题逐句解析，可「只练错题」。

## 双人 PK（左右分屏）

首页「模式」选 **双人 PK**，点「开始对战」。

- 屏幕左右各一位选手，各答各的题，**同时开始**，开场有 3-2-1 倒计时。
- 键位：**左边 `1 2 3 4`**，**右边 `7 8 9 0`**；触摸屏或没键盘时直接点自己那半屏的选项。
- 双方题目从同一题库里**按考点均分**，同考点题量一致、互不重复，公平对等。
- 各自独立计时：答对 +1 分并立刻换下一题；答错或超时也立刻换题（不扣分，比的是单位时间内答对多少）。
- 结束（时间到或点「结束」）：比总分定胜负，显示双方得分、答错数、超时数、最高连对。
- 选手名字可直接在左右上角点改（默认「左同学 / 右同学」）。
- 手机竖屏自动变成上下分栏，平板横屏是最舒服的用法；教室投屏用笔记本电脑全屏即可。

## 题库结构

`data/q1.js ~ q7.js` 每个文件是一批题目，格式：

```js
{id:"t01", tag:"时态语态", src:"高考真题",
 q:"Look! The children ______ (play) football on the playground.",
 o:["play","are playing","played","have played"], a:1,
 e:"Look! 是现在进行时的标志词，动作此刻正在进行。"}
```

- `q` 里用 `______` 表示空格，`(word)` 会被自动高亮成蓝色提示词；
- `o` 四个选项，`a` 是正确选项下标（0=A,1=B,2=C,3=D）；
- `e` 是解析，判定后立即显示；
- 加题直接在文件末尾追加即可，改完刷新页面就能看到。

题库分布（500 题）：时态语态 78 · 非谓语 80 · 词形转换 80 · 冠词 30 · 介词 35 · 代词 35 · 形容词副词 30 · 特殊句式 30 · 定语从句 28 · 名词性从句 27 · 主谓一致 25 · 状语从句 22。

> 已剔除两类高考语法填空基本不考的题：**零冠词（答案“不填”）** 和 **情态动词与虚拟语气**。
> 冠词题的四个选项为 `a / an / the / any`，全库不再出现“不填”这个选项。

来源说明：以历年高考语法填空真题语篇中的单句为素材，按考点改写为四选一（保留原提示词），标签统一标「高考真题」；部分句子为同考点真题式仿写。

## 内部工具（可删）

- `tools/check.js`：校验题库（题量、重复 id、答案下标、选项重复、题干重复）。`node tools/check.js`
- `tools/smoke.js`：用 Edge 无头浏览器跑一遍完整流程并截图。`node tools/smoke.js`

## URL 参数（演示 / 投屏用）

`index.html?go=1` 打开即开局；`?t=600` 改总时长（秒）；`?per=20` 改每题秒数。
